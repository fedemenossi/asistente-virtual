# Parametrizar la elegibilidad y los horarios de cada consultorio

La selección de Consultorios no se codificará con reglas particulares de un profesional. Cada Consultorio definirá sus Franjas de atención y Reglas de elegibilidad según modalidad, Primera consulta, tipo de cobertura y cobertura específica. El Asistente de WhatsApp evaluará esa configuración antes de ofrecer las Disponibilidades de las Fuentes de agenda automatizables, permitiendo incorporar casos como Caja Notarial sin modificar el Flujo guiado.
