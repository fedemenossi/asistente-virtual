# Confirmar explícitamente una previsualización temporal antes de emitir

Toda Factura manual mostrará una vista previa temporal antes de solicitar el CAE, sin guardar un borrador en la base de datos. Solo una confirmación explícita del operador creará el registro de emisión e iniciará la solicitud a ARCA, porque un comprobante autorizado es una operación fiscal irreversible.
