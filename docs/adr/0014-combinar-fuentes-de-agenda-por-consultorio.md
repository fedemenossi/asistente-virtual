# Combinar fuentes de agenda manteniendo la autoridad de cada consultorio

Cada Consultorio conservará una Fuente de agenda autoritativa, DrApp o Google Calendar. El Operador podrá generar masivamente slots para las agendas de Google, mientras el Asistente de WhatsApp consultará, normalizará y combinará disponibilidades elegibles de ambas fuentes; la retención, reserva, cancelación y reprogramación se ejecutarán siempre contra la fuente que originó cada horario.
