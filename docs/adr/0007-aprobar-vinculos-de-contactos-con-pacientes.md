# Aprobar manualmente nuevos vínculos entre contactos y pacientes

Cuando un Contacto de WhatsApp nuevo informa el DNI de un Paciente existente, el sistema no lo vinculará automáticamente ni revelará información del Paciente. Un Operador deberá aprobar la Vinculación de contacto, priorizando la protección de datos sensibles frente a una automatización completa basada solamente en el conocimiento del DNI.
