# Reprogramar asegurando primero el nuevo horario y conservando el pago

Una Reprogramación reutilizará el Contexto de elegibilidad del Turno original para buscar opciones equivalentes. El sistema reservará el nuevo horario antes de liberar el anterior, conservará la trazabilidad entre ambos y trasladará cualquier Pago aprobado sin iniciar un nuevo cobro; si la nueva reserva falla, el Turno original permanecerá intacto.
