# Permitir el envío opcional por email de comprobantes manuales autorizados

Después de recibir una autorización exitosa de ARCA, el operador puede elegir enviar por email el PDF de una Factura C manual. La entrega es posterior e independiente de la autorización, por lo que una falla o falta de dirección de email no altera el comprobante ni habilita una nueva emisión; se informará el estado y se podrá reenviar desde el detalle cuando exista una dirección válida.
