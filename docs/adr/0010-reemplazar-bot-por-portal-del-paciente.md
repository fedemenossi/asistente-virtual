# Reemplazar el bot de WhatsApp por un Portal del Paciente

La atención automática principal se realizará mediante un sitio web responsive propio de cada Tenant, no mediante un bot de WhatsApp. El Portal del Paciente conservará el enfoque de preguntas sucesivas para identificar al Paciente y recopilar datos, pero presentará las Disponibilidades elegibles de Google Calendar en una grilla semanal y permitirá reservar, cancelar y reprogramar Turnos con una interfaz visual.
