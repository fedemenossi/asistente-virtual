# Retener la disponibilidad durante una hora mientras se espera el pago

Cuando un Solicitante elige un horario para una Primera consulta con cobertura particular, el sistema lo bloqueará de forma exclusiva durante una hora mientras espera la confirmación del pago. Si no recibe un Pago aprobado dentro de ese plazo, liberará la Disponibilidad y el Turno pendiente de pago expirará; un pago acreditado después se convertirá en Saldo a favor del mismo Paciente y no recuperará el horario liberado. Las atenciones por obra social o prepaga y los Pacientes ya atendidos no pasan por esta retención.
