# Reprogramar asegurando primero el nuevo horario y conservando el pago

Una Reprogramación reutilizará la Cobertura del Turno y la condición de Primera consulta del Turno original, pero solicitará al Paciente que elija nuevamente la Modalidad de atención. Esa elección completará el nuevo Contexto de elegibilidad. El sistema reservará el nuevo horario antes de liberar el anterior, conservará la trazabilidad entre ambos y trasladará cualquier Pago aprobado sin iniciar un nuevo cobro; si la nueva reserva falla, el Turno original permanecerá intacto.
